## 🎮 Игровой процесс

Вы — оператор стелс-дрона **«ПРИЗРАК»**. Ваша задача — собрать разведданные с 5 объектов на вражеской базе, оставаясь незамеченным.

### 🔧 Механики:

- 🕹️ **Управление дроном** — WASD / Стрелки + Q/E (высота)
- 
- 👁️ **Система заметности** — враги видят вас в конусе обзора
- 
- 📡 **Сбор данных** — удерживайте прицел на цели 2 секунды
- 
- 🌡️ **Тепловизор** — клавиша `T` для подсветки врагов
- 
- 🗺️ **Радар** —实时 отслеживание врагов и целей
- 
- ⏱️ **Таймер** — 4 минуты на выполнение миссии

## 🕹️ Управление

| Действие | Клавиши |
|----------|---------|

| Вперёд/Назад | `W/S` или `↑/↓` |

| Влево/Вправо | `A/D` или `←/→` |

| Набор высоты | `Q` / `Shift` |

| Снижение | `E` / `Ctrl` |

| Сбор данных | Удерживать `ЛКМ` на цели |

| Тепловизор | `T` |
